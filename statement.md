1.Problem Statement
In big cities (eg. mumbai , delhi) ,finding short term parking space to park their car is quite one of its own challenge, resulting in traffic and wasted time. Simultaneously, private parking spaces remain vacant during working hours. There is no, local application to connect individuals with idle parking spots to drivers who need them.

2. Scope of the Project
This project is a terminal-based person-to-person parking rental platform , built using core Python data structures and Object-Oriented Programming (OOP). It allows users to register, list private parking spots, search for available spots, and simulate booking transactions.

3. Target Users
	1. Hosts: Individuals seeking to monetize their unused private parking allocations.
	2. Drivers (Renters): Commuters needing reliable short-term parking.

4.High-Level Features
- User Management: CLI-based registration and login system.
- Spot Management: OOP-based creation and storage of parking listings using lists and dictionaries.
- Booking & Billing Engine: Mathematical operators and type conversion to calculate booking durations and total costs.
