ParkShare CLI: Person to person Parking Platform

Overview
ParkShare is a Python-based CLI application, it solves urban parking problems by connecting drivers with parking persons. It relies entirely on Python fundamentals, core data structures, and Object-Oriented Programming to manage users, parking spots, and bookings.

Features
- Authentication: Secure terminal login using dictionary data structures.
- Host Dashboard: Add and view parking spots.
- Renter Interface: Browse available spots and calculate booking costs.
- Modular Design: Code is separated into specific packages to ensure maintainability.

 Technologies/Tools Used
- Language: Python 3.x
- Concepts Applied: Control Flow, Functions, OOP, Core Data Structures (Dictionaries, Lists), Type Conversion, I/O Operations.

Steps to Run the Project
1. Open your terminal or command prompt.
2. Navigate to the `ParkShareCLI` directory.
3. Run the application using the command: `python main.py`

Instructions for Testing
1. Launch the app and select option `1` to register a Host account.
2. Log in and select `1` to add a new parking spot.
3. Log out and register a Driver account.
4. Log in as the Driver, select `1` to view spots, and select `2` to book a spot.
